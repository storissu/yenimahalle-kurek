# WhatsApp metinleri (kopyalayıp gönderin)

`<...>` içindeki yerleri kendi bilgilerinizle değiştirin. Uygulamadaki **"Davet mesajını kopyala"** düğmesi, her üyenin kullanıcı adı ve geçici şifresini içeren kişisel mesajı zaten hazırlar; aşağıdaki **1. metin** grubun tamamına bir kez gönderilen duyurudur.

---

## 1. Grup duyurusu (bir kez)

```
Merhaba arkadaşlar 👋

Kulübümüzün antrenman uygulaması hazır: antrenmana katılıp katılmayacağınızı buradan bildireceksiniz, hangi tekneye ve hangi saate yazıldığınızı da buradan göreceksiniz. Ücretsizdir, mağazadan indirmek gerekmez.

Adres: <https://....pages.dev>

Nasıl yüklenir?
• iPhone: adresi SAFARİ'de açın → Paylaş → "Ana Ekrana Ekle"
• Android: adresi Chrome'da açın → ⋮ → "Uygulamayı yükle"

Size ayrıca özel bir mesajla kullanıcı adınızı ve geçici şifrenizi göndereceğim. İlk girişte kendi şifrenizi belirleyeceksiniz.

Lütfen ilk girişte bildirimleri de açın (Profil → Bildirimleri aç). Bir şey çalışmazsa bana yazın; hangi telefonu kullandığınızı yazmanız yeterli 🙏
```

## 2. Kişisel davet (uygulamanın "Davet mesajını kopyala" düğmesi bunu üretir)

```
Yeni Mahalle Kürek uygulaması
Adres: <https://....pages.dev>
Kullanıcı adı: <kullanıcı adı>
Geçici şifre: <şifre>
(İlk girişte yeni şifre belirlemeniz istenecek.)
```

> Şifre yalnızca bir kez gösterilir; mesajı gönderdikten sonra silebilirsiniz. Üye şifresini unutursa: Üyeler → üye → **Şifreyi sıfırla**.

## 3. Pilot için kısa istek (ilk 2 hafta)

```
İlk iki haftayı deneme olarak kullanıyoruz 🙂 Lütfen:
1) Her antrenmana uygulamadan yanıt verin,
2) Programı uygulamadan kontrol edin,
3) Anlamadığınız veya çalışmayan bir şey olursa bana yazın (ne yaptığınızı ve telefonunuzu belirtin).
Bu sürede WhatsApp'tan da duyurmaya devam edeceğim; sorun çıkarsa eski düzenle devam ederiz.
```

## 4. Yeni bir antrenman duyurusu (uygulama bildirim gönderir; WhatsApp'ta hatırlatmak isterseniz)

```
Yeni antrenman eklendi: <gün, saat>. Uygulamadan "Katılıyorum / Katılmıyorum" demeyi unutmayın. Son yanıt: <gün, saat>.
```

## 5. Program yayınlandı hatırlatması

```
<Gün> antrenmanının programı yayınlandı. Ana Sayfa'da "Sizin programınız" kutusundan tekneninizi ve saatinizi görebilirsiniz. Değişiklik gerekiyorsa bana yazın; program yayınlandıktan sonra yanıtlar kilitlenir.
```
